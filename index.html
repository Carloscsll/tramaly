Ajustes de imagen

Fondo

Lo que se quita queda vacío (sin cuenta), para que el dibujo se lea bien. Si prefieres rellenarlo, elige un color arriba. Ideal para fondos lisos; si no, usa la varita o el pincel.

Vista

De una foto a tu plantilla de cuentas

  1. Sube una imagen. Si el fondo es liso, se quita solo.
  2. Elige técnica y medida. Ajusta colores si quieres.
  3. Revisa la plantilla. Puedes corregir cuenta por cuenta.
  4. Compra y teje. Lista de materiales y guía paso a paso.

Varita: toca una zona del fondo para quitarla. Borrar/Restaurar: pinta sobre la imagen. El cuadriculado gris es lo que se quitó.
